# Домашняя работа №6: Docker-контейнер для статистического анализа

## Описание

Проект содержит R-скрипт для обработки данных о пациентах с последующим расчетом статистических показателей по уровню гемоглобина. Решение упаковано в Docker-контейнер для воспроизводимости на любой машине.

## Предварительные требования

На вашей системе должен быть установлен Docker. Проверить наличие можно командой:

```bash
docker --version
```

## Быстрый старт

### Сборка образа

Откройте терминал в директории с проектом и выполните:

```bash
docker build -t hemoglobin-analysis .
```

Команда создаст Docker-образ с тегом `hemoglobin-analysis`, включающий все необходимые зависимости и ваш скрипт.

### Запуск анализа

Для запуска контейнера с сохранением результатов на хост-машине выполните:

```bash
docker run --rm -v $(pwd)/output:/output hemoglobin-analysis
```

**Что происходит:**
- `--rm` — автоматически удаляет контейнер после завершения работы
- `-v $(pwd)/output:/output` — монтирует локальную папку `output` в контейнер для сохранения результатов
- Скрипт генерирует файл `анализ_гемоглобина.csv` в примонтированной директории

**Важно:** Убедитесь, что папка `output` существует перед запуском, либо создайте её:

```bash
mkdir -p output
```

## Результат работы

После успешного выполнения в папке `output/` появится файл `анализ_гемоглобина.csv`, содержащий агрегированные статистические показатели по группам пациентов.
